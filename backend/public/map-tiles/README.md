# بلاطات الخريطة المحلية (Offline Tiles)

ضع ملفات بلاطات الخريطة هنا ليعمل خيار **Offline** في خرائط النظام دون إنترنت.

## البنية المطلوبة

```
map-tiles/
  {z}/          # مستوى التكبير (zoom) — مثال: 10
    {x}/        # إحداثي X
      {y}.png   # البلاطة
```

مثال حقيقي:

```
map-tiles/10/674/415.png
map-tiles/11/1349/830.png
map-tiles/12/2698/1661.png
```

## التغطية المقترحة

- قصّ منطقة عملك فقط (مدينتك أو محافظتك) وليست العالم كله
- المستويات 8 إلى 17 تكفي للاستخدام الميداني
- حجم معقول: 1-3 GB لمنطقة واسعة حتى مستوى 17

## أدوات مقترحة لقص البلاطات

| الأداة | الملاحظة |
|--------|----------|
| Mobile Atlas Creator (MOBAC) | مجانية — اختر صيغة "OpenStreetMap tiles" وحدد الإطار والمستويات |
| QGIS + أداة Generate XYZ Tiles | مجانية — من قائمة المعالجات |
| tilemaker | لسطر الأوامر — من بيانات OSM الخام |

## كيف يخدمها الخادم؟

الخادم يقدمها تلقائياً على المسار:

```
GET /map-tiles/{z}/{x}/{y}.png
```

- لا تحتاج أي إعداد إضافي — ضع الملفات ثم أعد تشغيل الخادم
- الكاش مفعّل (7 أيام) لتحميل أسرع
- الوصول إليها لا يمر عبر حارس معدل الطلبات (Rate Limit)
