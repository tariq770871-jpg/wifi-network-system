■ ما الجديد في هذا التحديث؟

1) وضع اتصال SSH — بديل كامل عن خدمة api:
   لكل راوتر في التطبيق الآن خيار «وضع الاتصال بالراوتر»:
   - API  (المنفذ 8728 افتراضياً) — كما في السابق
   - SSH  (المنفذ 22) — الجديد: يقرأ نفس جدول Neighbors عبر اتصال
     SSH مشفّر، بنفس اسم المستخدم وكلمة المرور، ويعمل على RouterOS
     6.x و7.x — مخصص للراوترات التي لا تريد تفعيل خدمة api فيها.

2) دعم المنافذ المخصصة لكل راوتر:
   حقل المنفذ يقبل أي منفذ تكتبه. مثال: راوتر عندك فيه خدمة api
   مفعّلة على منفذ 1996 (وليس 8728)؟ اختر وضع API واكتب 1996 —
   يعمل فوراً بدون أي تعديل على الراوتر. راوتر آخر فيه ssh على
   منفذ 2222؟ اختر وضع SSH واكتب 2222.
   كل راوتر له وضع ومنفذ مستقل — لا يؤثر على باقي الراوترات.

3) شارة وضع الاتصال: بطاقة الراوتر المرتبط تعرض «مرتبط بـ MikroTik (SSH)»
   إذا كان متصلاً بوضع SSH.

4) عند اختيار وضع SSH يتبدل المنفذ تلقائياً (8728 ↔ 22) إن كنت
   ما زلت على الافتراضي — لا تحتاج تعديله يدوياً.

5) كل مزايا التحديث 3 كما هي: المزامنة التلقائية كل 10 دقائق،
   زر «جلب أجهزة MikroTik»، الفلاتر الأربعة (الشغالة/المنقطعة
   خلال 24 ساعة/أكثر من 24)، وزر Winbox مع سكربت التفعيل.

قرار صريح بطلب صاحب النظام — لا يتدخل في هذا الموضوع نهائياً:
- الأكتيف (Active / جدول التسجيلات اللاسلكية) — لا يُقرأ إطلاقاً
- قوة الإشارة — لا تُقرأ ولا تُعرض في أي مكان
- جدول ARP ومستأجرو DHCP — لا يُقرآن
(في الوضعين معاً: المصدر الوحيد هو جدول Neighbors — نفس قائمة Winbox)

■ كيف تربط كل راوتر حسب حالته؟ (اختر الحالة المناسبة لكل راوتر)

افتح تبويب «الأجهزة» ← أضف جهازاً أو عدّل جهاز الراوتر ←
فعّل «ربط MikroTik» ثم حدد «وضع الاتصال بالراوتر»:

الحالة (أ) — الراوتر فيه api مفعّلة (بأي منفذ):
  ✅ هذا الراوتر جاهز اليوم — بدون أي تعديل عليه!
  - الوضع: API
  - المنفذ: انظر الرقم المكتوب في الراوتر: IP ← Services ← api
    (مثال حقيقي من راوتراتك: api على منفذ 1996 → اكتب 1996)
  - اسم المستخدم وكلمة المرور: نفس بيانات Winbox (الأفضل مستخدم read)
  - اضغط «اختبار» ثم احفظ.

الحالة (ب) — الراوتر فيه api معطلة ولا تريد تفعيلها:
  فعّل خدمة ssh على الراوتر بدلها:
  1) Winbox ← IP ← Services ← خدمة ssh ← اضغط ✓ (تفعيل)
  2) دبل-كليك على ssh ← Available From ← اكتب عنوان جهاز الكمبيوتر
     الذي يشغّل النظام (مثال: 192.168.88.245) ← OK
     (فلا يمكن لأي جهاز آخر الوصول عبر ssh)
  3) أنشئ مستخدم قراءة فقط: System ← Users ← + ←
     Group = read ← اسم وكلمة مرور قوية ← استخدمه في التطبيق
  4) في التطبيق: الوضع = SSH ← المنفذ = 22 (أو المنفذ الظاهر
     في IP ← Services ← ssh) ← «اختبار» ← احفظ.

الحالة (ج) — الراوتر فيه api معطلة وتقبل تفعيلها:
  نفس خطوات التحديث 3: فعّل api (✓) ← Available From = عنوان
  جهاز النظام ← مستخدم read ← في التطبيق: وضع API + المنفذ 8728.

ملاحظة أمان مهمة — لاحظنا في راوتراتك:
- راوتر فيه خدمة telnet مفعّلة (23): تيلنت بروتوكول قديم غير مشفّر
  يُرسل كلمة المرور نصاً صريحاً — إذا لا تحتاجه فعّله: حدد سطر
  telnet في IP ← Services واضغط X (تعطيل). التطبيق لا يحتاجه أبداً.
- تأكد أن Available From مضبوط على الخدمات الحساسة (api / ssh)
  بعنوان جهاز النظام فقط.
- لا تفتح هذه الخدمات للإنترنت إطلاقاً (فايروول).

ملاحظة: الأجهزة التي تظهر في التطبيق = الأجهزة التي تظهر في
تبويب Neighbors في Winbox (MNDP/LLDP). إذا كان جهاز لا يظهر في
النيبرز فلن يظهر في التطبيق — وهذا مقصود (بدون الأكتيف وبدون
الإشارة) — سواء كان الراوتر متصلاً بوضع api أو ssh.

────────────────────────────────────────────────────────────────
■ كيف يعمل وضع SSH تقنياً؟ (الطريقة بالضبط)

1) التطبيق يفتح اتصال SSH مشفّراً بالراوتر (نفس بيانات دخول Winbox)
   على المنفذ الذي تحدده (22 افتراضياً).
2) ينفّذ أمر العرض النصي:
   /ip neighbor print terse without-paging
   الذي يطبع نفس سجلات تبويب Neighbors سطراً لكل جهاز.
3) يقرأ أيضاً /interface print لاستخراج MAC الراوتر نفسه واستبعاده
   من القائمة (كي لا يظهر الراوتر كجهاز مكتشَف).
4) يحفظ الأجهزة ويحدّث حالتها (شغالة/منقطعة) — كل 10 دقائق
   تلقائياً، أو فوراً بزر «جلب أجهزة MikroTik».

شرط واحد على الراوتر: تفعيل خدمة ssh (وapi إن اخترت وضع API).

────────────────────────────────────────────────────────────────
■ تفعيل زر Winbox بالنقرة الواحدة (اختياري — مرة واحدة — كما في التحديث 3)

1) في مجلد النظام ستجد الملف: setup-winbox-link.ps1
2) اضغط عليه بالزر الأيمن ← «Run with PowerShell»
3) اكتب مسار ملف winbox.exe على جهازك (مثال: C:\Tools\winbox.exe)
4) انتهى — زر Winbox في التطبيق يفتح Winbox بنقرة واحدة.
- بلا تفعيل: الزر ينسخ عنوان الاتصال تلقائياً — الصقه في Winbox.
- زر Winbox اختصار للإدارة فقط ولا علاقة له بجلب بيانات النيبرز —
  الجلب يعمل بدونه تماماً.

■ أسئلة شائعة — التحديث 4

س: أي وضع أختار لكل راوتر؟
ج: انظر IP ← Services في كل راوتر: إن كانت api مفعّلة → وضع API
   بالمنفذ المكتوب هناك. إن كانت معطلة → إما تفعيلها (الحالة ج)
   أو تفعيل ssh واختيار وضع SSH (الحالة ب). يظهر الوضع المختار
   على بطاقة الراوتر في التطبيق.

س: ظهرت رسالة «الراوتر رفض الاتصال — تأكد أن خدمة ssh مفعّلة...»؟
ج: خدمة ssh معطلة على الراوتر أو المنفذ غير صحيح. فعّلها (الحالة ب)
   وتأكد أن المنفذ في التطبيق يطابق الرقم في IP ← Services ← ssh.

س: ظهرت رسالة «فشل تسجيل الدخول — اسم المستخدم أو كلمة المرور»؟
ج: بيانات الدخول غير صحيحة لنفس الراوتر. كل راوتر له مستخدم وكلمة
   مرور خاصة به — تحقق منها في تعديل الجهاز.

س: ظهرت رسالة «دعم SSH غير مثبت على الخادم»؟
ج: شغّل start.bat مرة واحدة — سيثبّت دعم SSH تلقائياً (سطر [1b/4]).
   أو افتح موجه الأوامر داخل مجلد backend واكتب: npm install

س: ظهرت رسالة «أمر غير مدعوم على هذا الراوتر»؟
ج: تظهر فقط في تفاصيل المزامنة عند راوتر قديم جداً — الجلب يستمر
   بما توفّر. أرسل لي نص الرسالة وسأعالجه.

س: الجلب كان يعمل ووضعت الراوتر على وضع SSH فتوقف؟
ج: تأكد أن ssh مفعّلة على هذا الراوتر تحديداً وليس غيره — كل راوتر
   مستقل (وضعه ومنفذه ومستخدمه). جرّب زر «اختبار» في تعديل الجهاز.

س: هل تغيّر أي شيء في عمل وضع API؟
ج: لا — نفس السلوك تماماً. وضع ssh إضافة فقط.

س: راوتر api مفعّل على منفذ غير قياسي مثل 1996 — أكتب 1996 فين؟
ج: في تعديل الجهاز ← حقل «منفذ API». حقل المنفذ يقبل أي رقم
   1-65535 ويُستخدم للراوتر المعني فقط.

س: هل أعطي التطبيق «رابط وصول عن بعد» لمستخدم Winbox ليجلب البيانات؟
ج: لا — لا يوجد رابط ولا اتصال عبر برنامج Winbox. التطبيق يتصل
   بالراوتر مباشرة عبر api أو ssh بنفس بيانات الدخول، كما في
   التحديث 3، والآن لكل راوتر وضع يناسب حالته.

س: الجهاز كان شغالاً وصار في قائمة المنقطعة، لماذا؟
ج: كما في التحديث 3 — اختفى من تبويب Neighbors على الراوتر
   (انفصل/أُغلق). «آخر ظهور» يخبرك بالوقت.
